# 1. Microsoft Secure Score (Slides 54-55)


Microsoft Secure Score permite medir la postura de seguridad del entorno Microsoft 365, identificar riesgos y priorizar acciones de mejora basadas en recomendaciones de Microsoft. 【1-8dadcb】

* [BROWSER] https://security.microsoft.com
    * [MENU] Secure Score
        * 👁️ -> Puntuación actual
        * 👁️ -> Comparación con organizaciones similares
        * 👁️ -> Distribución por categorías

---

# 2. Acciones de mejora recomendadas (Slides 56-57)

Las acciones recomendadas ayudan a aumentar el nivel de seguridad del tenant, permitiendo priorizar controles según impacto, riesgo y esfuerzo de implementación. 【1-8dadcb】


* [BROWSER] https://security.microsoft.com
    * [MENU] Secure Score → Improvement actions
        * 👁️ -> Acciones recomendadas
        * 👁️ -> Puntos asociados a cada acción
        * 👁️ -> Estado de implementación
            * To address
            * Planned
            * Risk accepted
            * Resolved

---

# 3. Tendencias y seguimiento de Secure Score (Slide 58)

Secure Score permite analizar la evolución histórica de la seguridad del tenant y comparar el progreso frente a objetivos organizacionales y referencias del sector. 【1-8dadcb】

* [BROWSER] https://security.microsoft.com
    * [MENU] Secure Score
        * 👁️ -> Historical Trend
        * 👁️ -> Comparison Trend
        * 👁️ -> Score Changes
        * 👁️ -> Risk Acceptance Trend
