# Explorar etiquetas de confidencialidad (Slides: 13-21)

* [BROWSER] https://purview.microsoft.com

    * ## 1. Protección de datos mediante Sensitivity Labels (Slides 15-16)

    * [MENU] Solutions → Information Protection → Labels
        * 👁️ -> Las etiquetas pueden aplicar cifrado, marcas visuales y restricciones de acceso.
        * 👁️ -> Las etiquetas acompañan al documento o correo aunque cambie de ubicación.
        * 👁️ -> Las etiquetas pueden proteger archivos, correos, sitios y grupos.
        * 👁️ -> Las etiquetas pueden aplicar encabezados, pies de página y marcas de agua.

    * ## 2. Alcance, prioridad y subetiquetas (Slide 17)

    * [MENU] Solutions → Information Protection → Labels
        * 👁️ -> El Scope determina dónde puede utilizarse una etiqueta.
        * 👁️ -> El orden de las etiquetas define su prioridad dentro de la organización.
        * 👁️ -> Las subetiquetas permiten organizar etiquetas en grupos lógicos.
        * 👁️ -> Las subetiquetas no heredan la configuración de la etiqueta principal.

    * ## 3. Aplicación automática de etiquetas (Slide 18)

    * [MENU] Solutions → Information Protection → Auto-labeling
        * 👁️ -> Las etiquetas pueden aplicarse automáticamente cuando se cumplen determinadas condiciones.
        * 👁️ -> La clasificación puede basarse en tipos de información confidencial.
        * 👁️ -> Reduce la dependencia de la clasificación manual realizada por los usuarios.
        * 👁️ -> También puede recomendar etiquetas en lugar de aplicarlas automáticamente.

    * ## 4. Directivas de etiquetas de confidencialidad (Slide 19)

    * [MENU] Solutions → Information Protection → Label policies
        * 👁️ -> Las directivas publican etiquetas a usuarios y grupos específicos.
        * 👁️ -> Permiten definir una etiqueta predeterminada.
        * 👁️ -> Pueden exigir justificación cuando se reduce el nivel de clasificación.
        * 👁️ -> Permiten obligar a los usuarios a aplicar etiquetas en documentos y correos electrónicos.
