# 1. ¿Qué es Microsoft Viva Insights? (Slides 49-50)

## Mensaje principal

Microsoft Viva Insights analiza datos de colaboración de Microsoft 365 para proporcionar información sobre productividad, colaboración y hábitos de trabajo a nivel individual, equipo y organización.

## Demo

* [BROWSER] https://admin.cloud.microsoft/
    * [MENU] Show all
    * [MENU] Admin centers → Viva

* (NEW WINDOW)

* [BROWSER] https://admin.microsoft.com/Adminportal/Home#/vivainsights

    * 👁️ -> Microsoft Viva Insights
