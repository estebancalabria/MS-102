# 1. Estrategia de implementación de Sensitivity Labels (Slide 24)

## Mensaje principal

La implementación de etiquetas de confidencialidad debe formar parte de un proyecto planificado que contemple requisitos empresariales, pruebas piloto, validaciones internas y despliegue en producción. 【1-d52f69】

    * 👁️ -> Recomendaciones de despliegue

    * 👁️ -> Casos de uso empresariales

    * 👁️ -> Estrategias de adopción

# 2. Habilitar Sensitivity Labels para SharePoint y OneDrive (Slide 25)

## Mensaje principal

La habilitación de etiquetas de confidencialidad para SharePoint Online y OneDrive permite que los servicios procesen documentos cifrados y habilita funcionalidades como búsqueda, eDiscovery, DLP y coautoría. 【1-d52f69】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Information Protection → Labels

        * 👁️ -> Estado de integración con SharePoint y OneDrive

        * 👁️ -> Etiquetas con cifrado

        * 👁️ -> Compatibilidad con Office Online

        * 👁️ -> Procesamiento de contenido protegido

---

# 3. Requisitos para crear etiquetas de confidencialidad (Slide 26)

## Mensaje principal

Antes de implementar etiquetas es necesario revisar los requisitos de suscripción y licenciamiento, definir la clasificación de datos y determinar los controles de protección que utilizará cada etiqueta. 【1-d52f69】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Information Protection

        * 👁️ -> Labels

        * 👁️ -> Label Policies

        * 👁️ -> Opciones de protección disponibles

        * 👁️ -> Configuraciones de cifrado y marcado

---

# 4. Crear y publicar etiquetas de confidencialidad (Slides 27-28)

## Mensaje principal

Las etiquetas se crean en Microsoft Purview y posteriormente se publican mediante directivas que determinan qué usuarios o grupos pueden utilizarlas dentro de la organización. 【1-d52f69】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Information Protection → Labels

        * 👁️ -> Create a label

        * 👁️ -> Configuración de clasificación

        * 👁️ -> Configuración de cifrado

* [MENU] Information Protection → Label Policies

        * 👁️ -> Publish label

        * 👁️ -> Asignación a usuarios y grupos

        * 👁️ -> Configuración de directiva

---

# 5. Retirar y eliminar etiquetas de confidencialidad (Slide 29)

## Mensaje principal

Una etiqueta puede retirarse de una directiva para dejar de estar disponible a los usuarios o eliminarse definitivamente conservando la protección aplicada previamente a los documentos ya etiquetados. 【1-d52f69】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Information Protection → Labels

        * 👁️ -> Opciones de edición

        * 👁️ -> Retirada de una etiqueta publicada

        * 👁️ -> Eliminación de etiquetas

        * 👁️ -> Estado de etiquetas existentes
