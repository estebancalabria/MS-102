# [TEÓRICO] Implementación de Microsoft 365 Apps for enterprise (**Slides:** 32-45)  
---

# 1. Microsoft 365 Apps for enterprise (Slides 33-34)

Microsoft 365 Apps for enterprise proporciona las aplicaciones de productividad de Microsoft mediante un modelo de instalación y actualización basado en la nube. 【1-e898b3】

## Demo

* [BROWSER] https://admin.cloud.microsoft/
    * [MENU] Billing → Licenses
        * [ITEM] Microsoft 365 E3
            * 👁️ -> Apps incluidas en la licencia

---

# 2. Instalación Self-Service (Slide 35)

Los usuarios pueden instalar Microsoft 365 Apps directamente desde el portal de Microsoft 365 siempre que dispongan de una licencia válida. 【1-e898b3】

## Demo

* [BROWSER] https://portal.office.com
    * [BUTTON] Install apps
        * 👁️ -> Microsoft 365 Apps

---

# 3. Administración de instalaciones de Office (Slides 35-38)


Las organizaciones pueden permitir instalaciones realizadas por los usuarios o utilizar herramientas corporativas para realizar despliegues centralizados. 【1-e898b3】

## Demo

* [BROWSER] https://admin.cloud.microsoft/
    * [MENU] Settings → Org settings
        * [TAB] Services
            * [ITEM] Microsoft 365 installation options
                * 👁️ -> Permitir instalaciones por los usuarios

---

# 4. Actualizaciones de Microsoft 365 Apps (Slide 39)

Microsoft 365 Apps recibe actualizaciones continuas de seguridad, rendimiento y funcionalidades mediante el modelo Click-to-Run. 【1-e898b3】

## Demo

* [BROWSER] https://config.office.com
    * [MENU] Inventory
        * 👁️ -> Versiones instaladas
    * [MENU] Servicing
        * 👁️ -> Estado de actualización

---

# 5. Canales de actualización (Slide 40)

Las organizaciones pueden decidir con qué frecuencia reciben nuevas funcionalidades mediante distintos canales de actualización. 【1-e898b3】

## Demo

* [BROWSER] https://config.office.com
    * [MENU] Servicing
        * 👁️ -> Current Channel
        * 👁️ -> Monthly Enterprise Channel
        * 👁️ -> Semi-Annual Enterprise Channel

---

# 6. Microsoft 365 Apps Admin Center (Slide 41)

El Microsoft 365 Apps Admin Center centraliza la administración, análisis y supervisión de las aplicaciones de Office instaladas en la organización. 【1-e898b3】

## Demo

* [BROWSER] https://config.office.com
    * 👁️ -> Dashboard principal

---

# 7. Office Cloud Policy Service (Slide 41)

Las configuraciones de Office pueden administrarse de forma centralizada mediante políticas en la nube sin necesidad de utilizar Group Policy. 【1-e898b3】

## Demo

* [BROWSER] https://config.office.com
    * [MENU] Cloud Policy
        * 👁️ -> Políticas configuradas
        * [BUTTON] Create Policy

---

      * [BUTTON] Create
