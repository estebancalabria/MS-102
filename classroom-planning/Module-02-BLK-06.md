# [TEÓRICO] Implementación de Microsoft 365 Apps for enterprise
**Slides:** 32-45  
**Duración:** 75-90 minutos

---

# 1. Microsoft 365 Apps for enterprise (Slides 33-34)

## Mensaje principal

Microsoft 365 Apps for enterprise proporciona las aplicaciones de productividad de Microsoft mediante un modelo de instalación y actualización basado en la nube. 【1-e898b3】

## Demo

* [BROWSER] https://admin.cloud.microsoft/
    * [MENU] Billing → Licenses
        * [ITEM] Microsoft 365 E3
            * 👁️ -> Apps incluidas en la licencia

---

# 2. Instalación Self-Service (Slide 35)

## Mensaje principal

Los usuarios pueden instalar Microsoft 365 Apps directamente desde el portal de Microsoft 365 siempre que dispongan de una licencia válida. 【1-e898b3】

## Demo

* [BROWSER] https://portal.office.com

    * [BUTTON] Install apps

        * 👁️ -> Microsoft 365 Apps

---

# 3. Administración de instalaciones de Office (Slides 35-38)

## Mensaje principal

Las organizaciones pueden permitir instalaciones realizadas por los usuarios o utilizar herramientas corporativas para realizar despliegues centralizados. 【1-e898b3】

## Demo

    * [MENU] Settings → Org settings

        * [TAB] Services

            * [ITEM] Microsoft 365 installation options
