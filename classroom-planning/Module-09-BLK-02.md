# [TEÓRICO] Explorar etiquetas de confidencialidad
**Slides:** 13-21
**Duración:** 60-75 minutos

---

# 1. Protección de datos mediante Sensitivity Labels (Slides 15-16)

## Mensaje principal

Las etiquetas de confidencialidad permiten clasificar y proteger documentos, correos electrónicos y otros recursos mediante cifrado, marcas visuales y controles de acceso integrados en Microsoft Purview. 【1-769e16】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Information Protection → Labels

        * 👁️ -> Etiquetas existentes

        * 👁️ -> Nombre y descripción de cada etiqueta

        * 👁️ -> Configuración de cifrado

        * 👁️ -> Marcas visuales (Header, Footer, Watermark)

---

# 2. Alcance, prioridad y subetiquetas (Slide 17)

## Mensaje principal

Cada etiqueta posee un ámbito de aplicación específico, una prioridad dentro de la organización y la posibilidad de agruparse mediante subetiquetas para facilitar su uso por parte de los usuarios. 【1-769e16】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Information Protection → Labels

        * 👁️ -> Orden de prioridad de etiquetas

        * 👁️ -> Etiquetas padre e hijas

        * 👁️ -> Configuración de Scope

        * 👁️ -> Agrupación mediante Sublabels

---

# 3. Aplicación automática de etiquetas (Slide 18)

## Mensaje principal

Microsoft Purview puede aplicar automáticamente etiquetas de confidencialidad basándose en condiciones como tipos de información confidencial o patrones detectados en el contenido. 【1-769e16】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Information Protection → Labels

        * 👁️ -> Configuración Auto-labeling

        * 👁️ -> Condiciones de clasificación

        * 👁️ -> Tipos de información confidencial

        * 👁️ -> Recomendaciones automáticas de etiquetado

---

# 4. Directivas de etiquetas de confidencialidad (Slide 19)

## Mensaje principal

Las directivas permiten publicar etiquetas a usuarios y grupos concretos, configurar etiquetas predeterminadas y exigir justificación cuando se modifica la clasificación de contenido. 【1-769e16】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Information Protection → Label Policies

        * 👁️ -> Directivas publicadas

        * 👁️ -> Usuarios y grupos asignados

        * 👁️ -> Etiqueta predeterminada

        * 👁️ -> Configuración de justificación obligatoria

---

# Resumen del bloque

1. Comprender cómo las Sensitivity Labels protegen la información.
2. Analizar ámbitos, prioridades y subetiquetas.
3. Revisar el etiquetado automático de contenido.
4. Explorar las directivas de publicación de etiquetas.
5. Entender cómo Microsoft Purview aplica protección persistente a los datos.
