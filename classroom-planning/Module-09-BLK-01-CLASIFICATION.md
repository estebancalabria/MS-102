# Clasificación de datos confidenciales (Slides: 3-12)

* [BROWSER] https://purview.microsoft.com

    * ## 1. Clasificación de datos en Microsoft 365 (Slides 4-6)

    * [MENU] Solutions → Data Classification → Overview
        * 👁️ -> La clasificación permite identificar, categorizar y proteger contenido según su nivel de sensibilidad.
        * 👁️ -> Microsoft 365 utiliza Sensitivity Labels, Sensitive Information Types, Retention Labels y Trainable Classifiers.
        * 👁️ -> Data Classification proporciona visibilidad sobre el contenido clasificado existente en el tenant.
        * 👁️ -> Permite analizar contenido antes de implementar políticas de protección.

    * ## 2. Clasificadores entrenables (Slides 7-8)

    * [MENU] Solutions → Data Classification → Classifiers
        * 👁️ -> Existen clasificadores preentrenados y clasificadores personalizados.
        * 👁️ -> Los clasificadores utilizan ejemplos para reconocer tipos específicos de contenido.
        * 👁️ -> Los clasificadores pueden utilizarse con Sensitivity Labels, Retention Labels y Communication Compliance.
        * 👁️ -> Los clasificadores personalizados pueden volver a entrenarse para mejorar su precisión.

    * ## 3. Content Explorer y Activity Explorer (Slide 9)

    * [MENU] Solutions → Data Classification → Content Explorer
        * 👁️ -> Permite visualizar la cantidad y ubicación de los datos confidenciales.
        * 👁️ -> Permite filtrar por etiquetas o tipos de información confidencial.
        * 👁️ -> Muestra dónde se almacenan los datos detectados.

    * [MENU] Solutions → Data Classification → Activity Explorer
        * 👁️ -> Muestra actividades relacionadas con datos confidenciales y etiquetas.
        * 👁️ -> Permite revisar cambios de etiquetas y actividades de compartición externa.
        * 👁️ -> Ayuda a identificar comportamientos que podrían exponer información sensible.

    * ## 4. Huella digital de documentos (Slide 10)

    * [MENU] Solutions → Data Classification → Sensitive info types
        * 👁️ -> Document Fingerprinting crea una huella basada en patrones únicos de un documento.
        * 👁️ -> La huella puede utilizarse como un tipo de información confidencial.
        * 👁️ -> Permite detectar documentos similares enviados o compartidos fuera de la organización.
        * 👁️ -> Puede utilizarse posteriormente dentro de políticas DLP para proteger documentos específicos.
