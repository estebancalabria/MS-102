# 1. Gobernanza y cumplimiento en Microsoft Purview (Slides 4-5)

## Mensaje principal

Microsoft Purview proporciona una plataforma unificada para gobernar, proteger y administrar los datos de la organización a través de múltiples servicios de Microsoft 365. 【1-44bff2】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * 👁️ -> Soluciones disponibles en Purview

    * 👁️ -> Navegación Compliance

    * 👁️ -> Data Lifecycle Management

    * 👁️ -> Information Protection

# 2. Microsoft Purview Information Protection (Slide 6)

## Mensaje principal

Information Protection permite descubrir, clasificar y proteger información confidencial mediante etiquetas y políticas de protección. 【1-44bff2】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Information Protection → Labels

        * 👁️ -> Sensitivity Labels existentes

        * 👁️ -> Configuración de una etiqueta

# 3. Data Lifecycle Management (Slide 7)

## Mensaje principal

## Demo
