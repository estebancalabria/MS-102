# [TEÓRICO] Protección de endpoints con Microsoft Defender for Endpoint
**Slides:** 26-35
**Duración:** 60-75 minutos

---

# 1. Microsoft Defender for Endpoint (Slides 27-28)

## Mensaje principal

Microsoft Defender for Endpoint es una plataforma de seguridad para endpoints que combina sensores, análisis en la nube e inteligencia de amenazas para prevenir, detectar y responder a ataques. 【1-858f26】

## Demo

* [BROWSER] https://security.microsoft.com

    * [MENU] Assets → Devices

        * 👁️ -> Inventario de dispositivos

        * 👁️ -> Estado de riesgo

        * 👁️ -> Nivel de exposición

---

# 2. Integración con Microsoft Intune (Slides 29-30)

## Mensaje principal

La integración entre Intune y Defender permite administrar cumplimiento, riesgo del dispositivo y acceso condicional desde una plataforma unificada. 【1-858f26】

## Demo

* [BROWSER] https://intune.microsoft.com

    * [MENU] Endpoint Security → Microsoft Defender for Endpoint

        * 👁️ -> Conexión con Defender

* [MENU] Devices → Compliance policies

        * 👁️ -> Evaluación de riesgo del dispositivo

---

# 3. Onboarding de dispositivos (Slide 30)

## Mensaje principal

Los dispositivos Windows, Android e iOS pueden incorporarse a Defender for Endpoint para obtener protección, evaluación de riesgos y control de acceso. 【1-858f26】

## Demo

* [BROWSER] https://security.microsoft.com

    * [MENU] Settings → Endpoints → Device Management

        * 👁️ -> Métodos de incorporación

        * 👁️ -> Dispositivos incorporados

---

# 4. Vulnerability Management y Device Discovery (Slides 31-32)

## Mensaje principal

Defender Vulnerability Management identifica dispositivos administrados y no administrados, evalúa vulnerabilidades y prioriza acciones de remediación según el riesgo. 【1-858f26】

## Demo

* [BROWSER] https://security.microsoft.com

    * [MENU] Vulnerability Management → Dashboard

        * 👁️ -> Security Recommendations

        * 👁️ -> Vulnerabilidades detectadas

    * [MENU] Assets → Device Inventory

        * 👁️ -> Onboarding Status

---

# 5. Exposure Score y recomendaciones de seguridad (Slide 33)

## Mensaje principal

Exposure Score permite medir el nivel de exposición de la organización frente a amenazas y priorizar acciones para reducir el riesgo. 【1-858f26】

## Demo

* [BROWSER] https://security.microsoft.com

    * [MENU] Vulnerability Management → Dashboard

        * 👁️ -> Exposure Score

        * 👁️ -> Security Recommendations

        * 👁️ -> Impacto de las remediaciones

---

# Resumen del bloque

1. Comprender la arquitectura de Microsoft Defender for Endpoint.
2. Revisar la integración entre Intune y Defender.
3. Analizar el proceso de incorporación de dispositivos.
4. Gestionar vulnerabilidades mediante Vulnerability Management.
5. Utilizar Exposure Score para priorizar remediaciones.
