# [TEÓRICO] Gobernanza de datos en Microsoft Purview (**Slides:** 3-11)

---
# 1. Gobernanza y cumplimiento en Microsoft Purview (Slides 4-5)

Microsoft Purview proporciona una plataforma unificada para gobernar, proteger y administrar los datos de la organización a través de múltiples servicios de Microsoft 365.


* [BROWSER] https://compliance.microsoft.com
    * 👁️ -> Soluciones disponibles en Purview
    * 👁️ -> Navegación Compliance
    * 👁️ -> Data Lifecycle Management
    * 👁️ -> Information Protection

---

# 2. Microsoft Purview Information Protection (Slide 6)

Information Protection permite descubrir, clasificar y proteger información confidencial mediante etiquetas y políticas de protección.

* [BROWSER] https://compliance.microsoft.com
    * [MENU] Information Protection → Labels
        * 👁️ -> Sensitivity Labels existentes
        * 👁️ -> Configuración de una etiqueta
        * 👁️ -> Publicación de etiquetas

---

# 3. Data Lifecycle Management (Slide 7)

Data Lifecycle Management permite conservar o eliminar información mediante políticas de retención aplicadas a Exchange, SharePoint, OneDrive y Teams. 

* [BROWSER] https://compliance.microsoft.com
    * [MENU] Data Lifecycle Management → Microsoft 365
        * 👁️ -> Retention Policies
        * 👁️ -> Retention Labels
        * 👁️ -> Ubicaciones protegidas

---

# 4. Insider Risk Management (Slide 8)

Insider Risk Management ayuda a detectar, investigar y responder actividades de riesgo realizadas por usuarios internos. 

* [BROWSER] https://compliance.microsoft.com
    * [MENU] Insider Risk Management
        * 👁️ -> Templates de políticas
        * 👁️ -> Alertas de riesgo
        * 👁️ -> Casos de investigación

---

# 5. eDiscovery en Microsoft Purview (Slide 9)

eDiscovery permite buscar, preservar, analizar y exportar contenido para auditorías, investigaciones y requerimientos legales. 

* [BROWSER] https://compliance.microsoft.com
    * [MENU] eDiscovery
        * 👁️ -> Cases
        * 👁️ -> Searches
        * 👁️ -> Holds
        * 👁️ -> Review Sets
