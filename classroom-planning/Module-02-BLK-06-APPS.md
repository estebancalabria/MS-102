# [TEÓRICO] Implementación de Microsoft 365 Apps for enterprise (**Slides:** 32-45)  

---

# 2. Instalación Self-Service (Slide 35)

Los usuarios pueden instalar Microsoft 365 Apps directamente desde el portal de Microsoft 365 siempre que dispongan de una licencia válida. 

## Demo

* [BROWSER] https://m365.cloud.microsoft/apps
    * [BUTTON] Install apps
        * 👁️ -> Microsoft 365 Apps

---

# 3. Administración de instalaciones de Office (Slides 35-38)


Las organizaciones pueden permitir instalaciones realizadas por los usuarios o utilizar herramientas corporativas para realizar despliegues centralizados.

## Demo

* [BROWSER] https://admin.cloud.microsoft/
    * [MENU] Settings → Org settings
        * [TAB] Services
            * [ITEM] Microsoft 365 installation options
                * 👁️ -> Permitir instalaciones por los usuarios

---

# 4. Actualizaciones de Microsoft 365 Apps (Slide 39)

Microsoft 365 Apps recibe actualizaciones continuas de seguridad, rendimiento y funcionalidades mediante el modelo Click-to-Run. 

## Demo

* [BROWSER] https://config.office.com
    * [MENU] Inventory
        * 👁️ -> Versiones instaladas
    * [MENU] Servicing
        * 👁️ -> Estado de actualización

---

# 5. Microsoft 365 Apps admin center (Slide 40 - 41)

Las organizaciones pueden decidir con qué frecuencia reciben nuevas funcionalidades mediante distintos canales de actualización. 

## Demo

* [BROWSER] https://config.office.com
    * 👁️ -> Dashboard principal
    * [MENU] Inventory
        * 👁️ -> Equipos inventariados
        * 👁️ -> Versiones de Office
    * [MENU] Servicing
        * 👁️ -> Current Channel
        * 👁️ -> Monthly Enterprise Channel
        * 👁️ -> Semi-Annual Enterprise Channel
    * [MENU] Cloud Policy
        * 👁️ -> Políticas configuradas
        * [BUTTON] Create Policy
    * [MENU] Customization
      * [BUTTON] Create
            * 👁️ -> Selección de aplicaciones
            * 👁️ -> Canal de actualización
            * 👁️ -> Idiomas
