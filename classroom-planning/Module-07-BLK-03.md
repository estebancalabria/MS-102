# [TEÓRICO] Retención en Microsoft 365
**Slides:** 20-30
**Duración:** 60-75 minutos

---

# 1. Directivas y etiquetas de retención (Slide 22)

## Mensaje principal

Las directivas y etiquetas de retención permiten conservar, eliminar o conservar y posteriormente eliminar contenido en Microsoft 365. 【1-8f8a3f】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Data Lifecycle Management → Microsoft 365

        * 👁️ -> Retention Policies

        * 👁️ -> Retention Labels

        * 👁️ -> Publish Labels

---

# 2. Comparación entre Retention Policies y Retention Labels (Slides 23-24)

## Mensaje principal

Las Retention Policies actúan a nivel de ubicación mientras que las Retention Labels permiten aplicar configuraciones granulares sobre documentos y correos específicos. 【1-8f8a3f】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Data Lifecycle Management

        * 👁️ -> Retention Policies

        * 👁️ -> Retention Labels

        * 👁️ -> Diferencias de configuración

---

# 3. Ámbitos adaptables y estáticos (Slide 25)

## Mensaje principal

Las políticas de retención pueden aplicarse mediante ámbitos estáticos o adaptables para definir dinámicamente los usuarios, sitios o grupos afectados. 【1-8f8a3f】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Data Lifecycle Management → Adaptive Scopes

        * 👁️ -> Scope basado en atributos

        * 👁️ -> Scope estático

        * 👁️ -> Ubicaciones incluidas

---

# 4. Principios de retención y eDiscovery Holds (Slides 26-27)

## Mensaje principal

Cuando existen varias configuraciones de retención, Microsoft 365 aplica reglas de precedencia para determinar cuánto tiempo se conserva la información y cuándo puede eliminarse. Además, los eDiscovery Holds pueden impedir la eliminación permanente de datos. 【1-8f8a3f】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] eDiscovery → Cases

        * 👁️ -> Holds

        * 👁️ -> Preservation de contenido

        * 👁️ -> Ubicaciones retenidas

---

# 5. Preservation Lock (Slide 28)

## Mensaje principal

Preservation Lock impide que incluso los administradores globales reduzcan o eliminen configuraciones de retención ya protegidas. 【1-8f8a3f】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Data Lifecycle Management → Retention Policies

        * 👁️ -> Configuración de una política

        * 👁️ -> Opciones de bloqueo

        * 👁️ -> Restricciones aplicadas por Preservation Lock
