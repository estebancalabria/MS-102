# [TEÓRICO] Implementar Microsoft Purview Data Loss Prevention
**Slides:** 43-53
**Duración:** 60-75 minutos

# 1. Planificación de una implementación DLP (Slide 45)

## Mensaje principal

La implementación de DLP requiere identificar información confidencial, definir objetivos de protección, descubrir ubicaciones de datos y planificar las políticas antes de su despliegue. 【1-649d33】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Data Loss Prevention

        * 👁️ -> Página principal de DLP

        * 👁️ -> Ubicaciones compatibles

        * 👁️ -> Estrategia general de protección

---

# 2. Directivas DLP predeterminadas (Slides 46-47)

## Mensaje principal

Microsoft Purview incluye directivas DLP predeterminadas para dispositivos y Microsoft Teams que ayudan a detectar y supervisar información confidencial sin necesidad de configuraciones complejas. 【1-649d33】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Data Loss Prevention → Policies

        * 👁️ -> Directivas DLP existentes

        * 👁️ -> Templates incorporados

        * 👁️ -> Tipos de información confidencial protegidos

        * 👁️ -> Estado de una directiva

---

# 3. Diseño de una directiva DLP personalizada (Slides 48-49)

## Mensaje principal

Las organizaciones pueden crear directivas DLP personalizadas utilizando plantillas predefinidas o configurando reglas específicas según sus necesidades regulatorias y de negocio. 【1-649d33】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Data Loss Prevention → Policies

        * 👁️ -> Create Policy

        * 👁️ -> Templates disponibles

        * 👁️ -> Ubicaciones que pueden protegerse

        * 👁️ -> Condiciones y acciones configurables

        * 👁️ -> Simulation Mode

---

# 4. Notificaciones por correo electrónico (Slide 50)

## Mensaje principal

Las políticas DLP pueden enviar notificaciones automáticas a usuarios y administradores cuando se detectan actividades que incumplen las reglas configuradas. 【1-649d33】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Data Loss Prevention → Policies

        * 👁️ -> Configuración de User Notifications

        * 👁️ -> Email notifications

        * 👁️ -> Personalización de mensajes

---

# 5. Policy Tips para usuarios (Slide 51)

## Mensaje principal

Los Policy Tips informan en tiempo real a los usuarios cuando intentan realizar una acción que infringe una política DLP y pueden permitir excepciones controladas. 【1-649d33】

## Demo

* [BROWSER] https://compliance.microsoft.com

    * [MENU] Data Loss Prevention → Policies

        * 👁️ -> Configuración de Policy Tips

        * 👁️ -> Override options

        * 👁️ -> Report false positive

        * 👁️ -> Comportamiento de las sugerencias para usuarios
