# [TEÓRICO] Clasificación de datos confidenciales
**Slides:** 3-12
**Duración:** 60-75 minutos

---

# 1. Clasificación de datos en Microsoft 365 (Slides 4-6)

## Mensaje principal

La clasificación de datos permite identificar, categorizar y proteger el contenido según su nivel de confidencialidad o impacto. Microsoft 365 utiliza etiquetas de confidencialidad, tipos de información confidencial, etiquetas de retención y clasificadores entrenables.

## Demo

* [BROWSER] [Abrir Microsoft Purview](https://compliance.microsoft.com)

    * [MENU] Solutions → Data Classification

        * 👁️ -> Overview

        * 👁️ -> Etiquetas de confidencialidad detectadas

        * 👁️ -> Tipos de información confidencial detectados

        * 👁️ -> Ubicaciones del contenido clasificado

---

# 2. Clasificadores entrenables (Slides 7-8)

## Mensaje principal

Los clasificadores entrenables reconocen contenido mediante ejemplos y pueden utilizarse para aplicar etiquetas de confidencialidad, directivas de cumplimiento de comunicaciones y directivas de etiquetas de retención. Microsoft Purview incluye clasificadores previamente entrenados y clasificadores personalizados.

## Demo

* [BROWSER] [Abrir Microsoft Purview](https://compliance.microsoft.com)

    * [MENU] Solutions → Data Classification → Classifiers

        * 👁️ -> Clasificadores previamente entrenados

        * 👁️ -> Clasificadores personalizados

        * 👁️ -> Estado de cada clasificador

        * 👁️ -> Opciones para probar o volver a entrenar un clasificador personalizado

---

# 3. Content Explorer y Activity Explorer (Slide 9)

## Mensaje principal

Content Explorer proporciona visibilidad sobre la cantidad, el tipo y la ubicación de los datos confidenciales. Activity Explorer permite revisar las actividades relacionadas con datos y etiquetas, como cambios de etiqueta o uso compartido externo.

## Demo

* [BROWSER] [Abrir Microsoft Purview](https://compliance.microsoft.com)

    * [MENU] Solutions → Data Classification

        * 👁️ -> Content Explorer

        * 👁️ -> Filtrado por etiqueta o tipo de información confidencial

        * 👁️ -> Ubicaciones donde se almacena el contenido

        * 👁️ -> Activity Explorer y actividades detectadas

---

# 4. Huella digital de documentos (Slide 10)

## Mensaje principal

Document Fingerprinting permite crear una huella basada en el patrón de palabras de un documento y utilizarla como tipo de información confidencial para detectar documentos que contienen el mismo patrón.

## Demo

* [BROWSER] [Abrir Microsoft Purview](https://compliance.microsoft.com)

    * [MENU] Solutions → Information Protection → Classifiers → Sensitive info types

        * 👁️ -> Lista de tipos de información confidencial

        * 👁️ -> Creación de un tipo de información confidencial

        * 👁️ -> Opción Document fingerprint

        * 👁️ -> Carga del documento utilizado como plantilla
