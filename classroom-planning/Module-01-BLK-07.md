# 1. Alta de dominio personalizado (Slide 46)

## Demo

* [BROWSER] https://admin.cloud.microsoft/
     * [MENU] Settings → Domains
          * 👁️ -> Dominio onmicrosoft.com
          * 👁️ -> Dominios personalizados existentes
          * [BUTTON] Add domain
               * 👁️ -> Nombre del dominio
               * 👁️ -> Registro TXT de validación
               * 👁️ -> Registros DNS requeridos
               * 👁️ -> Estado de validación

# 2. Revisar configuración DNS del dominio (Slide 46)

## Demo

     * [MENU] Settings → Domains
          * [ITEM] Seleccionar dominio

               * 👁️ -> TXT
