# Implementar Microsoft Purview Data Loss Prevention (Slides: 43-53)

* [BROWSER] https://purview.microsoft.com

    * ## 1. Planificación de una implementación DLP (Slide 45)

    * [MENU] Solutions → Data Loss Prevention → Overview
        * 👁️ -> La implementación comienza identificando información confidencial que debe protegerse.
        * 👁️ -> Es necesario definir objetivos y requisitos de protección.
        * 👁️ -> Las organizaciones deben identificar las ubicaciones donde residen los datos.

    * ## 2. Directivas DLP predeterminadas (Slides 46-47)

    * [MENU] Solutions → Data Loss Prevention → Policies
        * 👁️ -> Microsoft Purview incluye políticas predeterminadas para dispositivos y Teams.
        * 👁️ -> Las políticas identifican tipos de información confidencial preconfigurados.
        * 👁️ -> Las políticas pueden revisarse, modificarse o deshabilitarse.

    * ## 3. Diseño de una directiva DLP personalizada (Slides 48-49)

    * [MENU] Solutions → Data Loss Prevention → Policies → Create policy
        * 👁️ -> Las directivas pueden crearse desde plantillas o desde una configuración personalizada.
        * 👁️ -> Permite seleccionar ubicaciones, condiciones y acciones.
        * 👁️ -> El modo Simulation permite validar el impacto antes de aplicar la directiva.

    * ## 4. Notificaciones por correo electrónico (Slide 50)

    * [MENU] Solutions → Data Loss Prevention → Policies → User notifications
        * 👁️ -> Las directivas pueden enviar notificaciones por correo electrónico.
        * 👁️ -> Los mensajes pueden personalizarse para usuarios y administradores.
        * 👁️ -> Las notificaciones informan sobre infracciones detectadas.

    * ## 5. Policy Tips para usuarios (Slide 51)

    * [MENU] Solutions → Data Loss Prevention → Policies → User notifications
        * 👁️ -> Los Policy Tips aparecen cuando una acción entra en conflicto con una directiva DLP.
        * 👁️ -> Los usuarios pueden recibir advertencias antes de completar la acción.
        * 👁️ -> Las directivas pueden permitir Override o Report false positive.
