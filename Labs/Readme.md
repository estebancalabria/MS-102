# Laboratorios MS-102

Este repositorio recopila los laboratorios del examen **MS-102: Microsoft 365 Administrator**.

Los labs están orientados a la administración integral de Microsoft 365, cubriendo identidad, seguridad, cumplimiento y colaboración.

---

## 🧪 Lista de Laboratorios

---

### 🔹 Lab 1: Configuración inicial del tenant

#### 1. Initialize M365 Tenant
**Objetivo:** Configurar el tenant de Microsoft 365 desde cero.  
**Resumen:** Se realiza la configuración inicial del entorno, incluyendo parámetros básicos de organización y acceso.

#### 2. Manage Users and Groups
**Objetivo:** Administrar identidades.  
**Resumen:** Creación y gestión de usuarios y grupos, asignación de licencias y configuración básica.

#### 3. Add a Domain
**Objetivo:** Agregar un dominio personalizado.  
**Resumen:** Se valida e integra un dominio propio en Microsoft 365 para uso corporativo.

---

### 🔹 Lab 2: Administración y monitoreo

#### 4. Manage Roles and Role Groups
**Objetivo:** Gestionar roles administrativos.  
**Resumen:** Asignación de permisos mediante roles predefinidos y grupos de roles.

#### 5. Monitor Microsoft 365
**Objetivo:** Supervisar el entorno.  
**Resumen:** Uso de herramientas de monitoreo, reportes y estado de servicios.

#### 6. M365 Apps
**Objetivo:** Administrar aplicaciones de Microsoft 365.  
**Resumen:** Configuración, despliegue y control de apps como Office.

---

### 🔹 Lab 3: Sincronización de identidades

#### 7. Prepare Identity Sync
**Objetivo:** Preparar sincronización híbrida.  
**Resumen:** Configuración previa para integrar identidades on-premises con Microsoft Entra ID.

#### 8. Implement Identity Sync
**Objetivo:** Implementar sincronización.  
**Resumen:** Uso de Azure AD Connect para sincronizar usuarios entre AD local y cloud.

---

### 🔹 Lab 4: Acceso seguro y privilegios

#### 9. Manage Secure User Access
**Objetivo:** Asegurar accesos.  
**Resumen:** Implementación de MFA y políticas de acceso condicional.

#### 10. PIM Admin Approval
**Objetivo:** Gestionar privilegios con aprobación administrativa.  
**Resumen:** Configuración de Privileged Identity Management con aprobación de un admin.

#### 11. PIM Self Approval
**Objetivo:** Activación de roles con autoaprobación.  
**Resumen:** Escenario donde el usuario puede activar roles privilegiados bajo ciertas condiciones.

#### 12. PIM Teammate Approval
**Objetivo:** Aprobación entre pares.  
**Resumen:** Configuración de aprobación de roles privilegiados por compañeros.

---

### 🔹 Lab 5: Protección contra amenazas (Defender)

#### 13. Safe Attachments
**Objetivo:** Proteger contra archivos maliciosos.  
**Resumen:** Configuración de políticas que analizan adjuntos en correos.

#### 14. Safe Links
**Objetivo:** Proteger contra enlaces maliciosos.  
**Resumen:** Reescritura y validación de URLs para prevenir phishing.

---

### 🔹 Lab 6: Alertas y simulaciones de ataque

#### 15. Prepare Alert Policies
**Objetivo:** Configurar alertas de seguridad.  
**Resumen:** Definición de políticas de alertas ante eventos sospechosos.

#### 16. Mailbox Permission Alert
**Objetivo:** Detectar cambios en permisos de correo.  
**Resumen:** Generación de alertas ante modificaciones en mailboxes.

#### 17. SharePoint Permission Alert
**Objetivo:** Detectar cambios en permisos de SharePoint.  
**Resumen:** Monitoreo de accesos a contenido compartido.

#### 18. eDiscovery Alert
**Objetivo:** Auditar actividades sensibles.  
**Resumen:** Alertas relacionadas a búsquedas o acciones de eDiscovery.

#### 19. Attack Simulation - Phishing
**Objetivo:** Simular ataques de phishing.  
**Resumen:** Uso de Attack Simulation Training para evaluar usuarios.

#### 20. Attack Simulation - Password Attack
**Objetivo:** Simular ataques de credenciales.  
**Resumen:** Escenarios de password spray o ataques similares.

#### 21. Validate Alerts and Attacks
**Objetivo:** Validar detecciones.  
**Resumen:** Verificación de alertas generadas y análisis de resultados.

---

### 🔹 Lab 7: Retención de datos

#### 22. Retention Policies
**Objetivo:** Gestionar ciclo de vida de datos.  
**Resumen:** Configuración de políticas de retención en M365.

---

### 🔹 Lab 8: Prevención de pérdida de datos (DLP)

#### 23. Manage DLP Policies
**Objetivo:** Configurar DLP.  
**Resumen:** Creación de políticas para proteger información sensible.

#### 24. Test DLP Policy
**Objetivo:** Validar DLP.  
**Resumen:** Simulación de escenarios para verificar funcionamiento.

---

### 🔹 Lab 9: Clasificación de información

#### 25. Implement Sensitivity Labels
**Objetivo:** Clasificar y proteger datos.  
**Resumen:** Uso de etiquetas de sensibilidad para proteger documentos y correos.

---

## 🧠 Conclusión

Los laboratorios de MS-102 son **100% prácticos (hands-on)** y cubren:

- Administración de identidades
- Seguridad y acceso
- Protección contra amenazas
- Cumplimiento y gobernanza

Son fundamentales para adquirir experiencia real como **Microsoft 365 Administrator**.
